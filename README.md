# Dragonwilds Server Mod Pack 🎮

This repository hosts the native `.pak` asset overrides and configuration files for our private server, "Lumbridge Landin".

### 🛠️ For Players: How to Sync Your Game
1. Make sure you have downloaded **`Update_Mods.bat`** and placed it on your desktop.
2. Run the script before launching the game to ensure your client matches the server configuration.
3. If the script alerts you that an update is available, press any key to automatically install the latest assets.
4. For the in game Password to join please contact a Friend for a (Invite Code).
